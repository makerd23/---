# Bejeweled Blitz 自動交換

適用於 Windows 上用 Chrome 開啟的 Facebook 版。由你登入並開始一局，程式接手交換寶石。

1. 雙擊 `start.cmd`，切到 Chrome 的 Bejeweled Blitz 分頁。
2. 在開局前按一次 **F2** 待命，接著用滑鼠按遊戲的開始按鈕。程式最多等待 30 秒，棋盤出現後會自動定位，等倒數結束才交換。
3. 保持棋盤完整可見，開局後維持視窗大小、網頁縮放和捲動位置。按 **F8** 可停止。遊戲的結算畫面會顯示分數。

在這個資料夾執行 `.\start.cmd --dry-run` 可先檢查辨識結果。操作相同，程式只會在終端機印出棋盤與建議走法。若將資料夾搬到另一台 Windows 電腦，需先安裝 Python 和套件，並在此資料夾執行 `py -3 -m pip install -r requirements.txt`。

若自動定位失敗，可執行 `.\start.cmd --manual`。先用一局顯示棋盤，游標指向棋盤左上、右下角各按一次 **F2**。只框 8×8 格，時間條和外框留在外面。下一局開局前再按 **F2** 待命。

若程式提早停止，同資料夾的 `blitz-last-run.log` 會記錄最近一次的定位進度和錯誤原因。

切到其他分頁或視窗時，程式會暫停操作。切回原本的遊戲分頁後會繼續偵測。遊戲自己的倒數可能仍在進行。

程式等倒數文字消失和棋盤連續兩幀一致，再嘗試交換。走法會依照四連、五連、交叉消除及可從目前棋盤預估的連鎖排序。權重是第一版的估計，實際分數需從遊戲結算驗證。特殊寶石的效果和新落下的寶石目前沒有納入預估。
